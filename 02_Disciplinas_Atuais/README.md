# Disciplinas Atuais

Disciplinas do modulo corrente. Ao fim do semestre, cada pasta concluida migra
para `04_Arquivo_Semestres_Anteriores/`.

| Pasta | Disciplina | Material versionado |
|---|---|---|
| `Bootcamp_I/` | Bootcamp I | Planejamento da arquitetura do Study Hub e entregas do Projeto Integrador. |
| `Projeto_Integrador_IV/` | Projeto Integrador IV | Documentacao do projeto, requisitos, diagramas e entregas parciais. |
| `Seguranca_Digital/` | Seguranca Digital | Resumos, estudos de caso e checklists de boas praticas de seguranca. |
| `Sistemas_Tempo_Real_e_Embarcados/` | Sistemas em Tempo Real e Embarcados | Anotacoes tecnicas, exercicios e codigos comentados. |
| `Teste_e_Qualidade_de_Software/` | Teste e Qualidade de Software | Planos de teste, casos de teste e scripts de validacao. |

Toda disciplina segue o mesmo par de subpastas: `Atividades_e_Entregas/` e
`Anotacoes_e_Resumos/`.
