# Teste e Qualidade de Software

Estratégias de teste, automação de validação, métricas de qualidade e prevenção de defeitos.

---

## Material versionado nesta pasta

Planos de teste, casos de teste, scripts de validação e relatórios de execução.

## Por que esta disciplina está no Study Hub

Garante que os projetos publicados no portfólio tenham qualidade comprovada, e não apenas código funcionando.

## Conexão com o restante do repositório

Fornece o critério de 'pronto' para qualquer projeto que entre em 03_Projetos_e_Certificados.
