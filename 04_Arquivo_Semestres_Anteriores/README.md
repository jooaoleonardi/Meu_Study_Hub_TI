# 04 — Arquivo de Semestres Anteriores

Disciplinas já concluídas, movidas de
[`../02_Disciplinas_Atuais/`](../02_Disciplinas_Atuais/) ao fim de cada semestre.

## Por que esta pasta existe

Sem ela, `02_Disciplinas_Atuais/` acumularia todas as disciplinas de todos os
semestres e perderia a função de mostrar **o que está em curso agora**. O
arquivamento mantém o repositório navegável sem jogar nada fora — o histórico
continua público e versionado.

## Estrutura

```
04_Arquivo_Semestres_Anteriores/
└── AAAA_Modulo_N/
    └── Nome_Da_Disciplina/
        ├── README.md
        ├── Atividades_e_Entregas/
        └── Anotacoes_e_Resumos/
```

Exemplo: `2026_Modulo_1/Seguranca_Digital/`

## Procedimento de arquivamento

Ao fim de cada semestre:

1. Criar a pasta do período: `AAAA_Modulo_N/`
2. Mover as pastas de disciplina concluídas de `02_` para dentro dela
3. Atualizar o índice acima
4. Atualizar a tabela de disciplinas no README principal
5. Commit: `chore(estrutura): arquiva disciplinas do modulo N`
