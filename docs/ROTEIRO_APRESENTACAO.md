# Roteiro da apresentação (5 minutos)

Fale em tom natural; os textos abaixo são uma base para você adaptar. Tempo total: ~5 min.
Grave a tela com o navegador aberto e siga a ordem das telas.

## 0:00 – 0:30 · Abertura
**Tela:** página no GitHub Pages (topo).

> Olá, eu sou o João Vitor Leonardi, estudante de Ciência da Computação no UniCEUB e
> Analista de Negócios Júnior. Neste vídeo apresento o meu repositório, o Meu Study Hub TI,
> e a página que publiquei com o GitHub Pages. É a entrega intermediária do Bootcamp I.

## 0:30 – 1:15 · Por que o repositório existe
**Tela:** README no GitHub (topo e "Propósito").

> Meu objetivo é ser a ponte entre o problema de negócio e a solução técnica. Meu LinkedIn
> mostra a parte de negócio; este repositório é onde construo a evidência da parte técnica.
> Todo material do curso fica num endereço único, versionado e público.

## 1:15 – 2:15 · Estrutura e organização
**Tela:** lista de pastas na raiz do repositório.

> A estrutura é numerada: 01 apresentação e perfil, 02 disciplinas atuais,
> 03 projetos e certificados, 04 arquivo dos semestres anteriores. Também tenho a pasta docs,
> com guia de Git, fluxo de trabalho e padronização, e a pasta de templates, para que todo
> projeto novo siga o mesmo modelo. Cada projeto tem sua pasta e seu próprio README.

## 2:15 – 3:15 · Versionamento
**Tela:** aba de commits, depois CHANGELOG.md e a lista de tags (releases).

> Uso Git com commits no padrão Conventional Commits: feat, fix e docs. O CHANGELOG registra
> as mudanças e cada versão tem uma tag. A versão 1.0 foi a criação da página do portfólio.
> A versão 1.1 acrescentou o projeto de força bruta em hash.

## 3:15 – 4:15 · Projetos e GitHub Pages
**Tela:** seção Projetos da página; depois README de `forca_bruta_hash`.

> A página reúne meu perfil, a estrutura do Study Hub, as disciplinas, os projetos e o contato,
> com tema claro e escuro e layout responsivo. Entre os projetos, o de força bruta em Python
> procura, em paralelo e usando vários núcleos, a string de sete letras que gera uma hash
> SHA-256 conhecida. O outro projeto é a própria página do portfólio, em HTML, CSS e JavaScript.

## 4:15 – 4:45 · LinkedIn
**Tela:** seu perfil no LinkedIn, seção Projetos.

> O repositório é público e está ligado ao meu LinkedIn, na seção de projetos, junto com o
> link da página publicada. Quem quiser conhecer meu trabalho consegue chegar a ele por ali.

## 4:45 – 5:00 · Encerramento
**Tela:** página no GitHub Pages (rodapé).

> O repositório continua crescendo ao longo do curso. Os links estão na descrição do vídeo.
> Obrigado!
