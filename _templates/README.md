# _templates

Modelos padronizados usados em todo o repositório. Copiar daqui em vez de
começar do zero garante que todo material tenha a mesma estrutura.

| Modelo | Quando usar |
|---|---|
| [`modelo_resumo.md`](modelo_resumo.md) | Ao resumir uma aula ou capítulo |
| [`modelo_atividade.md`](modelo_atividade.md) | Ao documentar uma entrega avaliada |
| [`modelo_projeto.md`](modelo_projeto.md) | Ao iniciar um projeto prático |

## Como usar

```bash
cp _templates/modelo_resumo.md \
   02_Disciplinas_Atuais/Seguranca_Digital/Anotacoes_e_Resumos/seguranca_resumo_tema.md
```

O prefixo `_` no nome da pasta a mantém no topo da listagem, separada do
conteúdo acadêmico numerado.
