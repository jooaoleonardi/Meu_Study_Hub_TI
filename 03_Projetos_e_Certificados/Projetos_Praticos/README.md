## Como adicionar um projeto

1. Crie a pasta com o nome do projeto em minúsculas e underscore: `nome_do_projeto/`
2. Copie [`../../_templates/modelo_projeto.md`](../../_templates/modelo_projeto.md) para `nome_do_projeto/README.md`
3. Preencha problema, solução, stack e instruções de execução
4. Adicione a linha correspondente no índice acima
5. Commit: `feat(projetos): adiciona projeto nome_do_projeto`
