# 03 — Projetos e Certificados

A vitrine do portfólio. É a pasta que um recrutador abre primeiro depois do
perfil, e a que melhor demonstra capacidade prática.

## Conteúdo

| Subpasta | O que guarda |
|---|---|
| [`Projetos_Praticos/`](Projetos_Praticos/) | Projetos autorais, com código e documentação própria |
| [`Certificados/`](Certificados/) | Certificados de cursos, eventos e trilhas concluídas |

## Critério de entrada

Um projeto só entra aqui quando atende aos três critérios:

1. **Funciona** — foi executado e produz o resultado prometido.
2. **Está documentado** — tem README próprio explicando problema, solução e stack.
3. **Foi validado** — passou pelos critérios de qualidade aprendidos em
   Teste e Qualidade de Software.

Projeto inacabado fica na pasta da disciplina que o originou, não aqui. Esta
pasta é vitrine, não rascunho.

## Estrutura de um projeto

```
Projetos_Praticos/
└── nome_do_projeto/
    ├── README.md          ← problema, solução, stack, como executar
    ├── src/               ← código
    ├── docs/              ← diagramas e documentação técnica
    └── assets/            ← capturas de tela e imagens
```

Modelo pronto em [`../_templates/modelo_projeto.md`](../_templates/modelo_projeto.md).
